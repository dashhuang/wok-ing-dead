## 全局

- **没有真人试玩过的东西很多**：节奏、手感、缺弹松紧、断肢和受击的观感大多只有机器人数据、测量和截图。现阶段不在浏览器里跑游戏
  （见 AGENTS.md「验证」），交付时要写清 Dash 试玩该重点看哪里。
- **声音没人实际听过**：武器音效、僵尸嗓音、环境声都只做过响度和频段测量（`arsenal/README.md`「检查与脚本控制」）。
- **手机真机性能没测过**。
- **许可**：僵尸角色和动作来自 Mixamo（不是 CC0），却已经公开部署；公开发布前要处理，来源逐个记在 [assets.md](assets.md)。
- 港区地图已移除，只保留金龙街；旧的 `?lvl=harbor` 链接进入唐人街，通关不再解锁码头。
  移除时的浏览器验证已通过；同步最新主分支后没有在浏览器里验证。试玩重点：标题页只有金龙街、旧链接可正常开局、结算后可再开。

## 对白与手机 UI（PR #24，2026-11-13）

- 无线电对白已改成整句显示的漫画面板，长段落按完整句子分页，暂停、选小票和武器轮盘会停住阅读计时。
- 手机按钮和四种弹药已改用统一线条图标；换弹是环形箭头，跳跃是向上箭头，弹药数量保留数字。
- 现有武器不开镜；闪电图标只在当前分支有副攻击时显示，按住使用、松开结束。切到没有副攻击的武器时隐藏并清掉旧触屏按压。
- 开发阶段看过桌面、手机横竖屏和 320px 窄屏，截图在 `docs/screenshots/comic-ui/`。同步最新主线后没有在浏览器里验证，
  等 Dash 试玩对白阅读时间、小屏图标辨识度、各分支副攻击键的显隐和松开发射；手机真机手感仍未确认。

## 武器

- 手感（后坐、上抬、散布、近战顿挫）和声音在 PR #11 重做，等 Dash 上手、试听后反馈；测量不算体验确认。
- 手腕（PR #13 后托枪的左手静止平均弯折 49° → 22°）。还没解决：判官、敕令、更夫的右手弯折仍大；判官、诸葛的左手在换弹起始瞬间略差。
  再有人提手腕或换弹，从这里继续，先读当前代码和测量工具（`arsenal/tools/arms.mjs`、`fit-grip.mjs`）。
- 试验场展柜：只有镇街、蜂巢、更夫托枪的手是算出来的；金钱剑的手臂从上方伸过来；手机横屏没看过。
- 礼花（PR #16）：只有礼花会炸到自己（`arsenal/src/data/weapons.js` 里的 `fire.self` / `selfMax`）。钉枪、喷火器热油、电弧球、连弩火矢这些会爆炸的都没有自伤。
  界面上没有「会炸到自己」的提示（加文案要重建四种语言的字体子集）。
- 受击（PR #17、#19）：只看过逐帧截图，没人看过连续动态。嫌飞得太远、太近，或者血太多、太少，先调 `arsenal/src/data/status.js` 的
  `launch.vary`、`blood.vary`、`blood.kill`，还有镇街的 `fire.shove` 和 `fx/effects.js` 的 `BLOOD`。
  实测：霰弹 2.5 米连杀五只，尸体飞出 4.6 / 1.6 / 4.7 / 3.2 / 2.0 米。

## 断肢（PR #18）

- 断肢概率和门槛是估的，等 Dash 试完再调（`arsenal/src/data/status.js` 的 `sever`，`src/chinatown/zombietune.js` 的 `limbs`）。

## 僵尸模型

- PR #10 接进七个 Mixamo 模型；PR #15 起其中五个进了套餐（`RUN.bodies`）：变异是招牌菜（关底）、剥皮巨人是精英、寄生是胀尸，
  黑帮是「猎手」精英，囚犯是第二道菜起成群冒出的小队。手机（low 档）用 512 px 贴图逐个加载。
- 小丑和南瓜巨人只在靶场（`/?range=1` →「僵尸 → 模型」，`&body=<名字>`、`&z=lineup`），不在正常的一局里。
  要删的话连同 `public/assets/zombies/` 里的 GLB 一起删。
- 单文件版因为新模型多了约 15 MB。原始 FBX 没入库：要重做就按 assets.md 记的来源重新取，用 FBX2glTF 加 `scripts/assets/build-zombies.mjs` 转。
