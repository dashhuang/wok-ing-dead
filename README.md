# 行尸走镬 Wok-ing Dead

雨夜的唐人街已经沦陷，接你的卡车要等三份外卖齐了才来。杀敌攒镬气、一路加菜，子弹自己捡，红包自己抢；点起三口灶，
颠锅、到点回灶、打包，关底「招牌菜」就会上桌，放倒它，再从东端的检疫关卡杀出去。

界面支持简体中文、繁體中文、English、日本語：首次打开按浏览器语言选择，标题页右上角和「设置」里可以随时切换，
`?lang=zh-CN|zh-TW|en|ja` 可直接指定。

本项目基于从 https://claude.ai/artifact/BGY1SztrAYcJQHSsnHHGmp 提取的浏览器 FPS「Saltline」（下载日期 2026-11-11），
保留原版的渲染、武器、输入和任务框架，把场景从集装箱码头换成唐人街，把敌人从机器人换成僵尸，并重做了名称、界面和文案。
目前只有金龙街地图；旧的 `?lvl=harbor` 链接也会进入唐人街。港区场景的[可读参考代码](references/saltline-harbor/README.md)和 `upstream/artifact.html` 原始发布包均保留。

## 开始开发

`main` 上的提交会自动部署到线上：小改动可以直接推 `main`，大改动走 Pull Request，流程见 [CONTRIBUTING.md](CONTRIBUTING.md)。
AI 编程助手的工作说明在 [AGENTS.md](AGENTS.md)。

需要 Node.js 22（参见 `.nvmrc`）。

```sh
npm ci
npm run dev
```

打开 http://127.0.0.1:5173/ 。点击「开镬」开始：WASD 移动，鼠标瞄准，左键射击，右键副攻击（部分武器分支可用；现有武器均不开镜），R 换弹，
数字键 1–9 按捡到的顺序选武器，滚轮依次切换，Q 回到上一把、按住 Q 打开武器轮盘，出小票时点小票或按 1 2 3 选，按住 E 切断警报器，
Shift 冲刺，C 蹲下，Esc 暂停。手机上点屏幕下方的武器栏换武器，长按「切枪」打开武器轮盘。浏览器需要 WebGL 2；鼠标锁定和声音需要一次真实点击。

```sh
npm run check    # JavaScript 语法、格式和数值护栏检查
npm run balance  # 改了数值后重新生成 docs/balance-report.md
npm run build    # 生成 dist/，包含本地调试 source map
npm run preview  # 预览构建产物
npm test         # 不开浏览器的测试（僵尸导航、游玩日志）
npm run verify   # check + build + npm test
npm run test:e2e # 浏览器里的真实点击冒烟测试（暂停使用；先 build，首次运行前 npx playwright install chromium）
npm run format   # 格式化开发文件
npm run build:single  # 生成单文件 dist-single/wok-ing-dead.html（约 35 MB，可直接双击打开或作为文件发送）
```

单文件版把脚本、样式、贴图、模型、音效和字体都以 base64 嵌在页面里，由页面开头的小段代码把 `assets/...` 请求转到这些内嵌数据。
所有字体都是仓库里的本地文件，构建不需要联网，页面运行时也不访问任何外部字体服务。

## 玩法

- **套餐**：一关约十分钟的肉鸽关卡（幸存者类）。规则在 `src/chinatown/run.js`，全部数值在 `src/chinatown/runtune.js` 的 `RUN` 里。
  - **三口灶**：死者不分波，持续涌来：前菜、热炒、大菜、猛火四道，越往后越多、越快，热炒起混入会自爆的「胀尸」。
    每点一口灶进入下一道。一口灶炒一道菜：颠三次锅（锅端在手上，开不了枪，可以走，每颠一下朝身前喷火），每次颠完放回灶上，菜自己炒，
    这段时间人可以走开，但到点要回来接着颠，回来晚了会糊，放太久就烧焦；三次之后打包带走。三袋外卖齐了，关底「招牌菜」上桌，放倒它出口才开，撤离即通关。
  - **武器不限数量**：开局「点主菜」三选一；之后升级小票里会出新武器，街上每局还有五个武器箱。手枪 LK-4 无限弹、最弱，保底用。
    共十四把：LK-9、LK-4 加上 `arsenal/` 里的十二把。开局只有六把可选，其余按累计战绩解锁（击杀数、见过关底、通关、
    关掉全部警报、中辣以上通关），存在 `wokingdead.profile.v1`。目前只开放微辣：中辣和变态辣在菜单上锁着，
    以后作为新关卡再开，所以「中辣以上通关」解锁的青龙关刀暂时拿不到。
  - **四种弹药，都要捡**：子弹、重弹、火货、五金，各有上限，同类武器共用；符箓和两把近战不吃弹药。来源是死者掉的弹药包
    （四种随机，手上那把缺的那种更容易出）、亮灯的补给箱（十二个位置里每局八个有货，每种两个，灯的颜色就是种类，
    取走后一分钟补一次，第一次要自己找；屏幕上的标记走近了才出现，远处靠灯找）、制服尸。打空了会自动换到还有弹的武器。
    **换一次弹，身上所有武器的弹匣都装满**（各扣各的弹药），所以打空了先切枪，找个空档再换弹。
  - **开局的街是安静的**：十几只行尸散在街上游走，不会主动过来；走近、打到它、或者在它附近开枪，它才扑上来。
    前菜阶段新出现的也是游走的，从热炒开始才直接冲着玩家来。
  - **灶的细节**：街上三处大排档的油桶灶（原来警报器的位置），开局都是冷的，顺序自定，一次只能炒一道。
    尸潮随三次颠锅逐级加码：第一次端锅时人少，第三次颠完最多，第二段开场来两群快尸，第三段来一只精英；每点过一口，
    下一口再凶一档。到点没回灶，过 15 秒糊一次（每糊一次奖励降一档），再放 30 秒烧焦（照样算一袋，但什么都不给）。
    每道菜都回血、给红包，另有三种随机的招牌（例汤加生命上限、备料补满并加弹药上限、利是多给红包），每局打乱，
    打包才揭晓。数值在 `RUN.stove`。
  - **不自动回血**：生命靠捡和选。击杀掉外卖盒（白盒子，回 25；血少时更容易掉，精英必掉三盒），
    老火汤加上限并立刻回这一截，关底登场前回满。数值在 `RUN.heal`。
  - **镬气换调料**：击杀攒镬气，满了升一级，三张小票选一张（十二种调料，各三层：伤害、射速、弹药上限、换弹、生命、移速、
    击杀爆炸、掉落，以及点燃、感电、蚀骨、贴符四种附魔）。选的时候街上几乎停住、画面压暗，鼠标放开，玩家停手点单，不限时间。
  - **精英与关底**：精英「硬菜」第 110 秒起每隔一分钟左右来一只，一只比一只血厚、手重，两种轮着来：
    剥皮的大个子血厚，黑帮打扮的「猎手」血少一半但追得上人、手更重；关底登场时玩家回满血。
  - **各有各的样子**：关底、两种精英、会自爆的胀尸和成群的快尸各用一个专门的模型（`RUN.bodies`），不再只靠发光的颜色区分。
    快尸三只一群，从同一个地方冒出来一起冲，血薄、比跑尸还快，从热炒开始出现。这些模型在开局后才下载，
    没到之前仍是原来的样子；角色贴图按画质分档（`zombietune.js` 的 `BODY_TEX`：`low` 全部 1024，`medium` 新模型 1024，更高用 2048 的原图）。
    手机默认是 `low`，在设置里调高后和电脑同样对待，重新进入页面后生效。
  - **红包升武器**：精英「硬菜」、出餐的灶和关底掉红包，捡到时**手上那把**升一级（最高五级）；升到三级时在甲、乙两种形态里选一种。
    一局大约十个红包：够把两把升满，或者把五把升到三级——专精还是全用，由玩家自己取舍。
  - **状态与反应**：灼烧、感电、蚀骨、镇压四种状态，两两相遇触发爆燃、导电雾、焚符、引雷。
  - **警报**：三座警报是可选的「爆单」：关一座引来半分钟尸潮，期间镬气翻倍，弹药补满，掉一个红包。
    结算时通关记 2 分，每关一座加 1 分。
- **吃到饱**：无尽波次，波次间补给和回血，记录最高分（沿用原版规则）。
- 僵尸：普通行尸（部分会奔跑，打断腿后改为爬行）、体型更大的重型僵尸；套餐里另有发绿光的胀尸（近身或被打死时爆炸，
  也会炸到旁边的死者）、发红光的精英和关底。爆头伤害 2.2 倍。
- 枪口下方有常亮的战术灯；红色油桶和气瓶可以引爆。

## 调试

- `window.__G`：游戏上下文（player / weapon / level / enemies / game 等）。
- `window.__ready`、`window.__fatal`、`window.__errors`：初始化和运行错误。
- `window.__stats()`：渲染统计和当前游戏状态。
- `/?autostart=1&noaudio=1`：跳过标题直接进入任务，便于冒烟验证。
- `/?cam=x,y,z,lx,ly,lz`：固定相机，`&noweapon=1` 隐藏武器，方便截图检查场景。
- `/?q=low|medium|high|ultra`：指定画质档位；`/?unlock=all`：全部武器解锁。
- `/?bench=1`：沿镜头路径巡航并统计帧耗时。
- `window.__G.run`：套餐关卡。`state` 是当前局的状态，`tune` 是全部数值，`loadout` 是武器和弹药；`debug.addXp(n)`、
  `debug.setTime(秒)`、`debug.envelope()`、`debug.pack("heavy")`、`debug.give("flamer")`、`debug.set("shotgun", 5, "b")`
  用来直接造出升级、关底、红包、弹药包、新武器，以及指定等级和形态的武器。`/?pool=1` 在电脑上也用手机的 30 只僵尸池。
- `/gallery/`：**陈列馆**，`arsenal/` 的展柜：看十二把武器的模型、双手、升级卡。构建站点时自动生成（`dist/gallery/`），
  首页顶栏有入口；开发服务器上这个地址会转到试验场（先 `npm run arsenal`）。
- `/?range=1`：**靶场**（首页顶栏也有入口）。就是套餐本身，只是关掉了时间线，换成左边一块面板手动摆（`src/chinatown/range.js`）：
  街道、僵尸、武器、调料、弹药、画面全是真的，所以在这里试到的就是玩到的。面板能把任意一把武器（含 LK-9、LK-4）调到任意等级和形态、
  给任意调料加层、弹药选「无限」或「套餐」、让僵尸「站桩 / 逼近 / 尸潮（按前菜、热炒、大菜、猛火的配比）」、单独召行尸、奔尸、重型、
  胀尸、精英、关底，看每秒伤害、击杀、受伤和耗弹；「模型」一行把还在试用的七个新僵尸模型（见 docs/assets.md）换上场——
  选一个就全由它来演，「新的混编」是七个一起上，「列队」让它们站成两排，模型选中时才下载；最下面的「数值」能在游戏运行时直接改共用的数值表（状态与反应、等级倍率、僵尸、弹药、
  调料、精英 / 关底 / 胀尸、特效亮度），「复制改动」列出改了什么、该写回哪个文件。Tab 松开 / 收回鼠标（不会暂停）。
  面板的状态记在地址里（`&w=&b=&lv=&spice=&ammo=meal&z=stand|advance|horde|lineup|none&course=&body=mix|<模型名>&god=0&tickets=1`），刷新回到原样——
  开发服务器每次存盘都会刷新，所以改代码、改数值表之后直接回到同一个场面。靶场不记战绩、不解锁。
- `/?w=flamer&b=a&lv=5&spice=chili:2,fire:3`：和武器试验场同一组地址参数。带着这把武器的这个形态（`b` 是 `a` / `b`，`lv` 1–5）
  和这些调料（`名字:层数`，名字见 `runtune.js` 的 `RUN.spices`）开局，跳过开局的三选一。在试验场里调好的配置换个地址就能进真实关卡试。
- `/?lang=ja`：指定界面语言（不写入存储）。

后台标签页的帧率会被浏览器限制，不应把自动检查时的后台帧率当作真实性能。
设置和纪录保存在当前站点的 localStorage；为了不丢失旧存档，设置和纪录仍沿用 `saltline.*` 键名，语言选择存于 `wokingdead.lang`，
套餐的解锁进度存于 `wokingdead.profile.v1`。
